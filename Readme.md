# 🎬 Netflix Frontend Clone

A visually accurate, fully responsive frontend clone of the **Netflix Landing Page** and user interface built using vanilla web technologies. This project focuses on replicating Netflix's modern dark layout, custom UI elements, and layout flow.


---

## ✨ Features

- **Responsive Landing Page:** Flawlessly scales across desktops, tablets, and mobile devices.
- **Accurate Branding:** Implements Netflix's signature black-and-red color scheme, custom typography, and layout.
- **Interactive FAQ Accordion:** Pure JavaScript toggles for the frequently asked questions section.
- **Dynamic Content Rows:** Horizontal, scrollable rows displaying movie and TV show banners.
- **Hover Micro-interactions:** Smooth CSS transitions and scaling effects on buttons and movie thumbnails.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure (headers, sections, nav, footers).
- **CSS3:** Flexbox, CSS Grid, custom variables for color theme, and media queries for responsiveness.
- **JavaScript (Vanilla):** DOM manipulation for interactive elements like the login modal simulation, email validation, or accordion toggles.

## ⚙️ How to Run Locally

Follow these quick steps to get the project running on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the directory:**
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. **Open the project:**
   Simply double-click the `index.html` file to launch it in any web browser, or run it using an editor extension like **Live Server** in VS Code.
